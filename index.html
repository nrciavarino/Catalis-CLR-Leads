Connection

Compass Leads stores everything in a Firestore database (Google's free-tier cloud database) so up to ~10 phones can read and write the same leads live. Paste your Firebase project config below — see the README that came with this app for the one-time project setup steps.

Badge photo reading (optional)

If a badge has no QR code, "No QR — take photo" can have Claude read the name/company/email off the photo automatically. This calls the Anthropic API directly from the phone using your own API key — it never touches Claude.ai. Leave blank to skip this and just type badges in manually.
