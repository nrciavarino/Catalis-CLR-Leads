Compass Leads stores everything in a Firestore database (Google's free-tier cloud database) so up to ~10 phones can read and write the same leads live. Paste your Firebase project config below — see the README that came with this app for the one-time project setup steps.

Competitors / current-software list

These populate the "Current software" dropdown on every lead. Shared with the whole team — add one here and everyone sees it within a few seconds.

Reason for engagement options

These populate the "Reason for engagement" dropdown on every lead. Shared with the whole team, same as the software list above.

Badge & business card photo reading (optional)

If a badge has no QR code — or you're photographing a business card instead — "No QR — take photo" can have Claude read the name/company/email off the photo automatically, badge or card either way. This calls the Anthropic API directly from the phone using your own API key — it never touches Claude.ai. Leave blank to skip this and just type badges in manually.

Send this setup to the rest of the team

Once the two boxes above are connected the way you want, generate a link that has both baked in. Anyone who opens it gets fully set up automatically — no copying or pasting on their end, no hunting for the Setup tab.

⚠️ This link contains your Firebase config and API key in plain sight (in the URL). Send it somewhere private — a direct message, not a public channel — and treat it like a password. Anyone with the link can read/write your leads and spend against your API key.

Your contact card

Fills in the QR code you can show attendees under "📇 My card" on the Scan tab — a two-way exchange: you scan theirs into a lead, then hand your own info back the same way. Your name comes from "Signed in as" on the Scan tab.
